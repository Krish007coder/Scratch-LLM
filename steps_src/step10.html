Entry Point (main.py)

How main.py ties the entire system together

1. Under the Hood: Entry Point Bootstrap

The entry point script main.py manages database initialization, pre-populates the vector index with semantic categories to demonstrate spatial separation, and starts the Flask server. It configures the server to bind to port 8080 and sets up multi-threaded request handling to prevent slow Ollama operations from blocking other requests.

2. Threaded Port Binding

By default, Flask runs a single-threaded server that handles requests sequentially. Since generating text embeddings or running conversational queries through Ollama can take several seconds, a single-threaded server would block all other incoming requests during inference. To prevent this, we set threaded=True to instruct the WSGI server to run request handlers in separate OS threads.

pythonfrom vectordb import OllamaClient, VectorDB, get_dist_fn
from vectordb.documentdb import DocumentDB
from server import create_app

DIMS = 16

def load_demo(db: VectorDB) -> None:
    dist = get_dist_fn("cosine")
    records = [
        ("Linked List: nodes connected by pointers", "cs",
         [0.90, 0.85, 0.72, 0.68, 0.12, 0.08, 0.15, 0.10, 0.05, 0.08, 0.06, 0.09, 0.07, 0.11, 0.08, 0.06]),
        ("Binary Search Tree: logarithmic lookup complexity", "cs",
         [0.88, 0.82, 0.75, 0.70, 0.10, 0.06, 0.12, 0.08, 0.04, 0.06, 0.05, 0.07, 0.06, 0.09, 0.07, 0.05]),
        ("Linear Regression: fitting a straight line to scatter data", "math",
         [0.15, 0.10, 0.08, 0.06, 0.92, 0.88, 0.78, 0.74, 0.08, 0.06, 0.05, 0.07, 0.09, 0.08, 0.06, 0.07]),
        ("Shao Mai: steamed pork dumplings topped with crab roe", "food",
         [0.08, 0.06, 0.05, 0.07, 0.09, 0.08, 0.06, 0.07, 0.12, 0.08, 0.06, 0.09, 0.95, 0.91, 0.82, 0.78])
    ]
    for meta, cat, emb in records:
        db.insert(meta, cat, emb, dist)

def main() -> None:
    db = VectorDB(DIMS)
    doc_db = DocumentDB()
    ollama = OllamaClient()
    
    # Pre-populate VectorDB with semantic clusters
    load_demo(db)
    
    app = create_app(db, doc_db, ollama)
    
    # Run the server on port 8080 with multi-threading enabled
    app.run(host="0.0.0.0", port=8080, threaded=True)

if __name__ == "__main__":
    main()
Code Analysis:
  • host="0.0.0.0": Configures the server to listen on all network interfaces, allowing external clients on the local network (LAN) to access the application.
  • threaded=True: Spawns a new OS thread to handle each incoming request, preventing slow CPU-bound distance computations or Ollama queries from blocking the main server loop.
