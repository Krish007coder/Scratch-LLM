1. Under the Hood: Memory Layouts

In Python, a standard list of floats is an array of pointers to double-precision float objects scattered across the heap. This causes pointer chasing and cache lines misses. By utilizing Python's __slots__ in our data containers, we restrict attributes dynamically, optimizing memory usage and eliminating the overhead of instance dictionaries.

2. Distance Metrics Mathematics

Our database implements three core distance metrics. For two vectors u and v in d dimensions:

  • Euclidean Distance (L2 Norm): Straight-line distance:
    D(u, v) = sqrt( sum( (u_i - v_i)^2 ) )
  • Manhattan Distance (L1 Norm): Sum of absolute differences:
    D(u, v) = sum( |u_i - v_i| )
  • Cosine Distance: Angular difference:
    D(u, v) = 1 - (u · v) / (||u|| * ||v||)
    If vectors are pre-normalized to unit length, this simplifies to 1 - u · v, bypassing divisions and square roots during search.

Distance Metric Implementation
pythonimport math
from typing import Callable, List

Vector = List[float]
DistFn = Callable[[Vector, Vector], float]

def euclidean(a: Vector, b: Vector) -> float:
    if len(a) != len(b):
        raise ValueError(f"Dimension mismatch: {len(a)} != {len(b)}")
    s = 0.0
    for x, y in zip(a, b):
        d = x - y
        s += d * d
    return math.sqrt(s)

def cosine(a: Vector, b: Vector) -> float:
    if len(a) != len(b):
        raise ValueError(f"Dimension mismatch: {len(a)} != {len(b)}")
    dot = na = nb = 0.0
    for x, y in zip(a, b):
        dot += x * y
        na += x * x
        nb += y * y
    if na < 1e-9 or nb < 1e-9:
        return 1.0
    val = dot / (math.sqrt(na) * math.sqrt(nb))
    val = max(-1.0, min(1.0, val))
    return 1.0 - val

def manhattan(a: Vector, b: Vector) -> float:
    if len(a) != len(b):
        raise ValueError(f"Dimension mismatch: {len(a)} != {len(b)}")
    return sum(abs(x - y) for x, y in zip(a, b))

def get_dist_fn(metric: str) -> DistFn:
    m = metric.lower()
    if m == "cosine": return cosine
    if m == "manhattan": return manhattan
    return euclidean
Code Analysis:
  • na < 1e-9 or nb < 1e-9: Safeguards cosine distance calculation against division-by-zero exceptions if one of the vectors is empty or zero-magnitude.
  • val = max(-1.0, min(1.0, val)): Prevents floating point precision errors from returning similarity scores outside standard mathematical boundaries.
