1. Under the Hood: PCA Dimension Reduction

To visualize high-dimensional vectors on a 2D web canvas, we must project their coordinates onto a 2D plane. Rather than relying on heavy server-side scientific libraries like scikit-learn, the frontend dashboard uses a custom JavaScript implementation of Principal Component Analysis (PCA) to project vectors dynamically in the browser.

2. Power Iteration Math

PCA identifies the principal components (eigenvectors) of the data covariance matrix that maximize coordinate variance. We use the Power Iteration numerical method to extract these eigenvectors. Given a centered data matrix X:

  1. Start with a random vector v.
  2. Multiply v by the covariance matrix:
    v_new = X^T * (X * v)
  3. Normalize the resulting vector:
    v = v_new / ||v_new||
  4. Repeat for a set number of iterations (e.g. 200) until the vector converges to the first principal component (PC1).
JavaScript UI Code Snippet
Client-side PCA Implementation
javascriptfunction pca2D(embs) {{
  const n = embs.length, d = embs[0].length;
  if (n < 2) return embs.map(() => [0, 0]);
  
  // 1. Calculate the mean along each dimension
  const mean = new Array(d).fill(0);
  for (const e of embs) {{
    for (let i = 0; i < d; i++) mean[i] += e[i] / n;
  }}
  
  // 2. Center the data by subtracting the mean
  const X = embs.map(e => e.map((v, i) => v - mean[i]));
  
  // 3. Power Iteration to find the first principal component (PC1)
  function powerIter(X_centered) {{
    let v = new Array(d).fill(0).map(() => Math.random() - 0.5);
    let norm = Math.sqrt(v.reduce((s, vi) => s + vi * vi, 0));
    v = v.map(vi => vi / norm);
    
    for (let it = 0; it < 200; it++) {{
      const Xv = X_centered.map(xi => xi.reduce((s, xij, j) => s + xij * v[j], 0));
      const nv = new Array(d).fill(0);
      for (let k = 0; k < n; k++) {{
        for (let j = 0; j < d; j++) nv[j] += X_centered[k][j] * Xv[k];
      }}
      norm = Math.sqrt(nv.reduce((s, vi) => s + vi * vi, 0));
      v = nv.map(vi => vi / norm);
    }}
    return v;
  }}
  
  const pc1 = powerIter(X);
  
  // 4. Project the centered data onto the PC1 axis
  return X.map(x => {{
    const projX = x.reduce((s, v, i) => s + v * pc1[i], 0);
    return [projX, 0]; // Visualized as coordinates on a 1D timeline / 2D graph
  }});
}}
Code Analysis:
  • X = embs.map(e => e.map((v, i) => v - mean[i])): Centering the data is necessary for PCA because it aligns the principal components with the axes of maximum variance relative to the dataset's center.
  • nv[j] += X_centered[k][j] * Xv[k]: Performs matrix-vector multiplication without allocating intermediate matrix objects, optimizing performance in client-side Javascript.
