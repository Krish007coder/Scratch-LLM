Prerequisites & Setup

Preparing the environmental parameters and verifying system requirements

1. Environmental Requirements

  • Python 3.9+: Isolating dependencies inside a virtual environment prevents version conflicts.
  • Ollama: The local model runtime platform.
  • System Memory: Minimum 8GB RAM is recommended to run local language models. llama3.2:3b requires approximately 4GB of RAM/VRAM to run inference.

2. Under the Hood: Memory Footprint of Local Models

Local large language models run directly on your hardware. For example, a 3-billion parameter model like llama3.2 stored in 4-bit quantized format takes up around 2.0GB of disk space. During execution, it must be loaded into memory (RAM or GPU VRAM). If your system lacks a dedicated GPU with sufficient VRAM, Ollama automatically falls back to CPU-bound execution, which degrades generation speed from ~40 tokens/sec to ~5 tokens/sec. nomic-embed-text is a lighter, 137-million parameter model requiring only ~270MB of RAM.

3. Step 1 — Configuring Virtual Environment & Python

First, create and activate a Python virtual environment to isolate the project dependencies:

bash# Create a virtual environment named .venv
python -m venv .venv

# Activate on Windows (Command Prompt)
.venv\Scripts\activate.bat

# Activate on Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Activate on macOS/Linux
source .venv/bin/activate

# Verify versions
python --version
pip --version
⚠️
Windows execution policy warning

If PowerShell throws an error stating script execution is disabled, run the command Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process and try activating the environment again.

4. Step 2 — Launching and Pulling Ollama Models

Ollama runs as a background service listening on port 11434. Pull the text-embedding model and the generative language model:

bash# Pull the embedding model (768-dimensions)
ollama pull nomic-embed-text

# Pull the 3B parameter conversational model
ollama pull llama3.2

Verify that the models are installed and registered:

bashollama list

5. Step 3 — Install Dependencies

Our project uses standard HTTP and web routing capabilities. Install the required libraries:

bashpip install flask requests

6. Production & System Design Trade-Offs

Local Models vs Cloud APIs:

  • Local (Ollama): Zero usage costs, full offline capability, absolute data privacy. However, inference latency is bound to local hardware (CPU/GPU) performance.
  • Cloud APIs (OpenAI/Cohere): Highly scalable, sub-second responses, but requires internet connection, usage-based billing, and sends user data to external servers.
